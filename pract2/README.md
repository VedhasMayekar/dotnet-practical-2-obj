# Practical 2 — C# Object-Oriented Programming

**Aim:** Write C# programs for object-oriented concepts:
- Classes and objects
- Constructor overloading
- Function overloading
- Inheritance
- Namespaces

## Run in Visual Studio 2026
1. Open `pract2.csproj`.
2. Select the .NET 8 SDK.
3. Run the project.
4. Enter a number from 1 to 8 to select a demonstration.

## Demonstrations
1. Classes and objects
2. Function overloading
3. Constructor overloading
4. Single inheritance
5. Hierarchical inheritance
6. Multilevel inheritance
7. Multiple inheritance through interfaces (C# uses interfaces rather than multiple base classes)
8. Namespace alias

The examples are consolidated into one runnable console project so each concept can be selected from the menu.
